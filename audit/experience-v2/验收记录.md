## 追加：半脸上妆（2026-09-24 · 可选的一步，买的是信息不是钱）

手背试色看不出来的那件事，原来在规则里没有出口：她没说出口的诉求只能靠那三个固定问题问出来，问完就到底了。新增 `faceTrialService` / `faceTrialReveal` / `FACE_TRIAL_MINUTES = 2`：试用之后可以主动提出在她半边脸上上妆，多占两分钟，露出她「最在意却还没说出口」的那一条诉求（权重最高的一条未知诉求）。两个 UI 都调同一个 `faceTrialReveal`，不各写一份。

代价与边界（全部由规则用例量出来，不是写进断言的期望值）：

- 钱不变。同一位顾客，上脸上不上脸成交额一分不差（`assert.equal(seen.campaign.sales, blind.campaign.sales)`）；这一步买的是「你知道」，不是「你多卖」。
- 时间从队伍另一头扣。`spendAttention` 走原路，手机版顶部那句「梅女士 4/8 → 2/8」就是这一笔；沙盘 `.shift-clock` 精确 +2 分钟。
- 明知故犯另算。上脸看过、知道不合适还强推，信任 −4、台账 −4，历史多一行「她照着镜子看过这半张脸，还是买了」，成交文案多一句「她知道不合适，你也知道」；营业额照收。
- 一支只能上一次脸；换一支产品等于重新上脸，但她说出口的那条不会忘掉（`faceTrialRevealed` 保留、`faceTrialled` 复位）。
- 存档新增两个字段，旧存档缺字段按未上脸处理；`faceTrialled` 非布尔、`faceTrialRevealed` 不是已知诉求时整条存档拒收。

全柜十位客人都量过一遍：每一位都能在试用后再上脸露出至少一条未知诉求（`shen/mei/zhao/anjie/returning/duan/zhou2 → steady`，`xiaoyu/zhou → correct`，`anjie2 → correct`），不是只给沈薇做的演示关卡。

## 追加：去面板感第二轮——体力、记录本、进度条（2026-09-24）

上一轮列下的三个裸数字这一轮全部收掉，另外补上一个真正的规则缺口：`evidence`（五天留痕）从写进存档以来没有任何一条规则读过它，「五天记录」一直是装饰。

改了什么：

- 体力念成一句：`energyWord()` + `consultsLeft()`，一格按实测最贵的一单算（`ENERGY_PER_CONSULT = 24`；干净一单实测 17，被陆遥打断那一单 24）。沙盘栏 `体力 62 / 100`、手机版结果页 `剩余体力 62`、现场那行 `剩余体力 62 · 低于 18 时不能新开接待`、dock 里额外的「体力见底，接不了新人」全部换成同一句「还站得住，能再接 4 位」。值班手册里那句写死的「体力低于 18」改成读 `ENERGY_LOCK`。
- 记录本念成一句：`evidenceWord()`（摊得开 / 没几行 / 空着），分界线只有 `RECORDS_MIN = 4`。手机版今日账单原来的「证据 3」换成这句。写这一节的时侯发现沙盘栏位根本没提过本子（`src/` 里 `evidence` 出现 0 次），玩家要到第 5 晚才第一次知道有这本账——补上 `.rail-records`「记录本 空着 / 没几行 / 摊得开」，和第 5 晚问的是同一个 `evidenceWord`、同一条线。
- 留痕第一次有读者：第 5 晚 `argue-records` 由本子决定落点——摊得开 +10 柜位点、挂 `counter-argued-records`、判词「柜位留到季度末」；空着只 +3、不挂旗、判词仍是「撤柜评估已经写上去」。判词认旗不认分数，所以空本子摊开不能被骗成「留到季度末」。事件正文和选项说明先把「摊开来没几行」讲出来，不让人盲选；她没看完的那两页也不再算新留痕（只有摊得开才 +2），否则今日账单会反过来打脸。
- 两根进度条一起撤：沙盘 `.target-track`、手机版 `.sales-progress`。差多少只在页顶说一遍，达标后页顶念「五日 ¥21,000 已经做到」——原来那里会念「还差 ¥0」。

## P10 · 楼层上第二个当场付的动作：迎上去（一支小样换她不走）

## P11 · 屏一矮，控制台把站在柜台前的人整块盖住了

为什么先动这一处：P10 自己记下的边界。那一轮把余量量成 21px 就当通过了，没往矮屏走过一遍——而 21px 是"这台屏刚好够"，不是"这条规则成立"。

先量，量出来这不是文案问题：地面按百分比排（人站在 43%~62% 那一圈），控制台是固定像素高的浮层，屏越矮盖得越多。改之前（Playwright + 无头 Chromium，dev server 绑 127.0.0.1）——390×844 控制台顶 546.84、最低名牌底 525.87（余 21px）；390×667 顶 371.84 / 底 417.90，盖住 46px；320×568 顶 255.45 / 底 357.51，盖住 102px。

改了什么（只在手机版 `Prototype.tsx` / `prototype.css`，规则层没动）：

- `.player-console` 从"内容多高就多高"改成按屏幕比例封顶：`max-height:34svh`。34svh 在 390×844 上正好等于原来那份 287px，主屏看不出变化；屏矮了面板就跟着矮。
- 面板内部拆成两段：`.console-head`（她是谁 / 她说了什么 / 还有谁在等，装不下时在面板里滚，`overscroll-behavior:contain` 不把滑动交给页面）+ 钉死的动作行与那句计时提示（`flex:none`）。金色主操作和那行理由永远不用先滚动才按得到。
