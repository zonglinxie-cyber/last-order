# Blender 导出规范（喂回现有 PWA）

只换图，不换引擎。Blender 渲完 PNG / spritesheet，覆盖 `public/assets/game/` 即可。不要导出 glTF，不要进 Godot。

对照板放在 `art/templates/`。在 Blender 里用 **Empty Image / Background** 叠进去套准。

| 模板 | 用途 |
|---|---|
| `templates/walk-cell-384x512.png` | 单格走路/待机 |
| `templates/consultation-853x1844.png` | 咨询近景脸位与 UI 遮挡 |
| `templates/stage-waypoints-853x1844.png` | 柜台底板脚位 |

## 1. 死规矩

- 玩家许愿**不上现场地板**。她只出现在工牌、半身像、第一人称手势。
- 现场角色是 **3.0–3.5 头身时装玩具**，不是写实小人，也不是大头 Q 版。
- 咨询近景可以更像美妆广告，但五官、发型、衣服必须和现场玩具能对上号。
- 所有走路帧**只朝右**。左转由游戏 `scaleX(-1)` 翻转。任何一帧朝左都会闪头。
- 透明底 PNG。不要烘地面大阴影（CSS 已加接触阴影）。脚底允许极浅椭圆，不得超过格宽 40%。
- 画面里不要画 HUD、对话框、线索圆点、手、试妆台 UI。那些是程序。

| 资产 | 像素 | 现网路径 |
|---|---|---|
| 柜台底板 | 853 × 1844 | `public/assets/game/counter-stage-toy.png` |
| 顾客走路表 | 1536 × 1024（4×2，单格 384 × 512） | `public/assets/game/toy-customers-walk.png` |

## 3. 柜台底板

脚位是角色锚点（按钮 `translate(-50%, -88%)`，点在脚附近）：

| 路点 | 左% | 上% | 谁站 |

| entrance | 12 | 62 | 进场 |
| aisle | 20 | 56 | 过道 |
| tester | 31 | 43 | 第一顾客 / 试妆台 |
| testerSide | 42 | 47 | 第一顾客不耐烦 |
| open | 53 | 55 | 第二顾客 |
| openLow | 44 | 57 | 第二顾客不耐烦 |

上 80px 是时钟和进度，下 280px 是检查器。家具和花瓶不要挡这些脚位。试妆岛大约在 `tester`，收银在 `checkout`，入口在左下。

## 4. 现场走路图

### 格子

- 单格 **384 × 512**，脚踩格底中心红框。
- 头顶留 8–16px，脚离底边 8–16px。
- 正交相机，3/4 右侧身，和舞台俯角一致。不要纯侧视。
- 原点：脚底中点。Blender 里角色站在世界原点，相机看 +Y 或 -Y，角色面朝 +X。

### 表怎么拼

`toy-customers-walk.png` 和 `toy-staff-walk.png` 都是：

```
[ 帧1 接触 ] [ 帧2 交叉 ] [ 帧3 接触 ] [ 帧4 摆腿 ]
行 0 = 第一种身体
行 1 = 第二种身体
```

循环 0.64–0.70 秒。权重移动要小，不要滑步。第 3 格必须仍朝右。

| 文件 | 行 0 | 行 1 | 游戏实际用几帧 |
|---|---|---|---|
| `toy-customers-walk.png` | 年轻客 | 熟龄客 | 4 |
| `toy-staff-walk.png` | 绮光柜员（米金制服） | 维珞柜员（深紫制服） | 前 3 格（第 4 格可放待机） |

顾客身体型：

- 年轻：沈薇、小雨、安姐、周姐、段小姐
- 熟龄：梅女士、赵女士

第一版共用身体型即可。身份靠咨询脸和 28px 圆徽章区分。有余力再出「一人一表」。

### 最小姿态

每一种身体至少：

1. 待机（可放第 4 格，或单独一行以后再接）
2. 走路 4 帧
3. 不耐烦/看表（顾客急走时用；没有就先复用走路）

不要做玩家可控走位。这些只是现场气氛。

## 5. 咨询近景

### 构图

- 画幅 **853 × 1844**，竖构图，顾客看向镜头（柜姐视角）。
- **脸必须落在高度 22%–52%**。再往下会被发现卡片和试妆台挡住。
- 上 12% 是顶栏，13%–22% 是台词，不要把眼睛放到那里。
- 线索圆点由程序画。渲图时让解剖位置对准下面三个中心：

| 线索 | CSS | 在 853×1844 上的中心 |
|---|---|---|
| 眼下 `eyes` | `left:30%; top:36%` | (278, 686) |
| 鼻翼 `nose` | `left:48%; top:43%` | (432, 815) |
| 脸颊 `cheek` | `right:25%; top:44%` | (618, 834) |

允许 ±20px。对不准，玩家会点到头发或背景。

赵女士、段小姐的线索不一定长在她们自己脸上（礼物单）。仍按同一张脸位出图，程序会改文案。

### 表情清单

文件名先按「一人一张默认图」替换现网。表情多出来用后缀，代码以后再切。

| 后缀 | 何时用 | 表演 |
|---|---|---|
| （无）/ `-idle` | 默认、开口 | 看镜头，礼貌但有防备 |
| `-focus` | 正在点线索 | 微侧，让人检查皮肤 |
| `-ask` | 被问到痛点 | 认真，眉眼松开一点 |
| `-trial-pos` | 试对产品 | 镜中确认，肩放松 |
| `-trial-neg` | 试错产品 | 皱眉、摸脸、嫌厚或刺激 |
| `-close` | 准备结账 | 决定中，不是假笑 |
| `-leave` | 不耐烦 / 要走 | 看表或看通道（咨询里备用） |

**第一批最少：** 每人 `idle` + `trial-pos` + `trial-neg`。现在游戏只用滤镜模拟后两种，有真图再换。

不要在一张脸上画左右分屏前后对比。那是咨询参考图里的 UI，不是底图。

## 8. Blender 怎么出

### 走路 / 半身

- 正交相机，锁定 384 × 512。
- 角色脚对世界原点。
- 胶片透明，PNG RGBA。
- 灯光：暖白主光从画面左上，弱紫补光，避免影把剪影切碎。
- 材质：搪胶 + 布料高光，不要皮肤次表面写实。

### 咨询

- 透视 50–85mm，竖构图，浅景深可以，但眼下/鼻翼/脸颊必须清楚。
- 输出 853 × 1844，色彩管理 sRGB，不要过曝高光把肤质抹平。
- 线索区要看出干纹、泛红、出油或起皮，手机上看也在。

### 舞台

- 正交或长焦俯视，画幅 853 × 1844。
- 把 `stage-waypoints-853x1844.png` 叠在相机上对脚位。
- 烘焙到一张板，不要导出场景给引擎。

### 命名

覆盖现网文件名就能玩。表情多图用：

```
customer-shen-consultation.png
customer-shen-consultation-trial-pos.png
customer-shen-consultation-trial-neg.png
```
