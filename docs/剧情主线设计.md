# 剧情主线设计 · 把"没玩就结束了"改成一个能玩两季以上的主线骨架（2026-10-09）

诊断和外部参照在 `docs/剧情深度调研.md`（那里有实测的燃烧曲线：一半池子在第 18～20 天烧掉、两季重复率 50%、135 张平均 166 字、42 人只有 12 人有线）。这份文档只写**我们要怎么做**，并且标明每一块是"已经落地、有测试钉住"还是"下一步、还没写"。

## 0. 一句话

**一条贯穿几季的主线，靠玩家一块一块攒起来的证据翻面；翻面的那一刻不是有人告诉你真相，而是你自己记下过的三行字对到了一起。**

三条缺口对三个部件：

| 缺口（实测） | 部件 | 状态 |
|---|---|---|
| 一次性消耗完，没有悬念跨季 | **主线本子**（幕号 + 线索 + 线的收法，跨季带着走） | 已落地，1 条线 4 条线索 |
| 30/42 的人没有线，线走完就没了 | **闸门 + 引力井**（推进即清零、走完留可重复替代卡） | 未做 |
| 50% 时段在读重复内容，说书人只过滤合法性 | **世界钟 + 张力义务**（计量到刻度才放卡；每两个时段必须端一张高张力的） | 未做 |

## 1. 已落地：主线本子的规则（有测试钉住）

契约在 `src/world/types.ts`，数据在 `src/world/content/clues.ts`，卡在 `src/world/content/storylets-mainline.ts`。

**三个状态，全部是 quality，全部跨季携带**（`CARRIED_QUALITY` 里含 `clue:` / `thread:` / `mainline:` 三个前缀）：

- `clue:<id>` = **学到那条线索的绝对天数**（第 2 季第 5 天学到 = 33，不是 5）。引擎 `learnClue` 幂等：已经记着就不覆盖，`hasClue` 只认值 >0。
- `thread:<线>` = 这条线的**收法落点**，0 = 没弄清，≥1 = 落到第几档。注意落点是**互斥的几种结局**，不是进度，所以档案里存的是"见过的几种收法"（`threadEnds: Record<string, number[]>`），跟个人线 `arcEnds` 同一个口径。
- `mainline:act` = 幕号。**幕号串行是防烧的第一道闸**：下一幕的卡 `when` 里钉 `{quality:"mainline:act",eq:N}`，上一幕没走完，后面的卡**根本不进合法牌堆**（不是加权降低，是不存在）。

**线索的读写只有两个入口**：效果 `{clue:"id"}` 写、条件 `{clue:"id"}` 认。界面（档案的「本子」页、季末回顾的「本子上的事」）只读 `clues.ts` 那张表，**不在 UI 里拼句子**。

**反转的门槛（`main-slip-turn`）**：必须同时握着 `slip-hand`（日期）+ `slip-borrowed` 或 `slip-tape` 至少一条，且第 12 天之后、沈薇在场。四个选项落四档，其中"这单就是沈薇退的"这一档有**两个同名选项**，用 `{not:{knowsSecret:"shen"}}` / `{knowsSecret:"shen"}` 分开 —— 你已经知道她秘密的人，同一句谎话代价更重（看法 −22/−12 对 −20/−10）。

**防卡死的阀门（`main-slip-filed`）**：第 24 天起，如果还没挣到收法，沈薇自己把单子并进柜位的账，落第 5 档「说好」。规则测试钉的是：**任何一张写 `thread:*` 却不以 `{clue}` 为门的卡，日期下限必须 ≥20** —— 阀门不能提前，否则主线又被白送。

**线索不能是死信**：每条线索必须被至少一张卡的 `when` 用到（`world-clues` 里查）。四条 act-1 线索卡各有一条"链式入口"（`{clue:"slip-hand"}` 之类），所以**先拿到日期的人后面更容易撬开另外三条** —— 这一条是实测逼出来的：没有链式入口时只有 21% 的局能翻面，加上以后是 **67.5%（54/80）**。

**现在的实测基线**（`tests/world-sim.ts 20 2`，80 局跑完两季，改内容后不能往下掉）：

| 指标 | 基线 |
|---|---|
| 两季翻到第 2 幕 | 80/80 |
| 本子上攒到的条数（中位） | 老实/狠推 3/4，八面玲珑/乱来 2/4 |
| 拧过来的线 | 80/80 |
| 挣来的收法（1～4 档） | 54/80（16 / 16 / 11 / 11） |
| 阀门档（第 5 档「说好」） | 26/80 |
| 主线卡出场率 | open 80/80（第 4 天）、fang 74、shen 66、song 52、yin 30、turn 54（第 17 天）、filed 26（第 25 天） |

**读出来的两个问题**：`main-slip-yin` 只有 30/80 —— 尹小洁本人上场率太低，这条线索基本拿不到；四档收法里"等档案自己走到台面上"和"这单就是沈薇退的"各只有 11，玩家大多选了前两条。这两条是第 3 节要修的。

## 2. 四幕架构：一季两幕，反转是"重读"不是"追加"

`MAINLINE_ACTS` 现在只写到第 2 幕。目标形状（**未做**，除标注外）：

| 幕 | 什么时候开 | 玩家已经付过的代价 | 这一幕把那句话改成什么 |
|---|---|---|---|
| 1 一张署了别人名字的单子 | 第 1 季第 4 天起（已落地） | 方敏问"这张脸你接没接过" | —— |
| 2 名字在谁手里 | 第 1 季第 12 天起（已落地） | 本子上 ≥2 条线索 | **退单的人不是沈薇，是"用沈薇名字的那群人"，而你手里那条日期是你自己的**（`slip-tape` 里那句"录进去的是你的原话"） |
| 3 柜位的账 | 第 2 季（未做） | 第 1 季的收法落点 + 柜位/台账两个数 | **对面维珞请走的那个人，是第 1 季你亲手签过字的那位** —— 用 `arc:<人>:end` 和 `wechat:` 旗重读，不新增信息 |
| 4 谁在写单子 | 第 3 季（未做） | 三条线各自的收法 | **退货单这个动作本身是这层的规矩**：每一季的第一张单子由玩家自己签。类型从"卖货 + 查案"翻成"你就是流程" |

三条硬规矩，从调研里抄来的（公平推理那节）：

1. **每一幕的收束卡都只引用玩家已经被给过的东西** —— 不许"灵光一闪"、不许突然出现没讨论过的知识。写成规则测试：收束卡的 `when` 与正文里的 `{...}` 槽，必须能在**更早的卡**里找到来源（线索、秘密、arc 落点、看法）。
2. **反转要落在状态上，不落在台词上**。每档收法必须改一个可核对的东西：某人的 `opinion`、`arc:<人>:end`、柜位/台账、或者**移除**一条 quality（第 3 幕打算用"你把 `clue:slip-tape` 交出去了，本子上那一行被划掉"）。当前 10 张主线卡里已经有 opinion 和 `thread`/`act`，**还没有一档会移除或改写玩家已有的东西** —— 这是第 3 幕必须补的。
3. **锁要看得见**。档案的「本子」页已经把"没攒到的压成？？？"、"没拧到的收法压成？？？"，头部念 `本子上攒了 N / 4 条`。新增线沿用同一套渲染，**不许**新增进度条或数值面板。

## 3. 四条线：一条已有，三条要写

`CLUE_THREADS` 只有 `return-slip`。目标 **4 条线**（第 2 节每幕牵一条），每条线的规格先定死，写的时候照表填：

| 线 | 抛出的问话 | 4 条线索从哪来（日常玩法的副作用） | 四档收法 + 阀门 | 结构形状 |
|---|---|---|---|---|
| 那张退货单（已有） | 单子上写的是沈薇，退的不是她。那是谁？ | 日期（方敏）/ 名字是借的（宋姐）/ 录音（尹小洁）/ 领用表缺口（方敏） | 交出去 / 只说名字 / 不开口 / 咬沈薇 /（阀门）并账 | Chain + 一次 Hourglass（四条线索悄悄填同一个计量） |
| 差的那三天（新，第 2 季幕 3） | 沈薇"没上过这层楼"的那三天，柜上的监控在拍谁？ | 保安高原的排班、段小姐的取货时间、老康的一句话、维珞的会员记录 | 说出来 / 只说一半 / 换个人问 / 装作不知道 /（阀门）监控自己坏了 | Clock（套钟：排班 → 记录 → 人证） |
| 谁在替谁带货（新，第 2 季幕 3 并行） | 群里那句"两周能看出来"，是谁先起头的？ | 米朵的截图、裴岚的承认、赵宁的账、你自己的 `remembers` | 认下来 / 指给她 / 交给苏蔓 / 谁都不给 /（阀门）话自己传开了 | Wheel（可重复：每季都能再起一轮，但每轮的起头人不同） |
| 柜位租约（新，第 3 季幕 4） | 这面镜子明年还在不在？ | 台账、巡店告示、陆遥的一份合同、唐可的一次人情 | 签 / 拒 / 谈条件 / 让给别人 /（阀门）季末自动到期 | Hourglass（前面三季的所有 `thread` 落点各贡献一格） |

写每条线时**必须同时做的事**：

- 每条线索的 `about` 至少两个人 —— 线索是关系的产物，不是道具。
- 每条线要有一张"链式入口"卡：拿到 A 的人更容易拿到 B（第 1 季那四条已经这么做，实测把翻面率从 21% 抬到 67.5%）。
- **阀门卡的日期下限 ≥20**（规则测试钉死），并且阀门那一档要**有代价**：现在第 5 档只扣 4 点看法，太轻，改成"下一季开局少一条本子上能念的话"。
- 收法落点要**能被第 2 季的卡读到**（`{quality:"thread:return-slip",eq:1}` 这种），否则收法只是档案里的一行字。

## 4. 闸门与引力井：让 30 位没线的客人和走完的线都有去处

**这是"没玩就结束了"最便宜的一刀**，调研里排第 1、第 2 的杠杆。

1. **推进即清零**（抄 P5R）：个人线每落一档，把 `arc:<人>` 归 0，靠 `arc:<人>:end` 记住走到哪。现在 `arc:<人>` 是单调涨的，所以一条线能在一季里连推四档。目标：**一季之内同一个人最多推一档**，靠这个把八条线的完成数从 80/80 压到 40～55/80。
2. **里程碑而不是抽卡**（抄 Wildermyth / 活侠传）：个人线卡改挂到**结构时刻** —— 她第 3/7/15 次来店、节日、季末 —— 而不是 `{present:X}` + 加权。需要新增一个"她来过几次"的计数 quality（`visits:<id>`，跨季携带）。
3. **引力井**（抄 FL）：**每条走完的线原地留 2～3 张可重复替代卡**，用她新的状态做门（`{quality:"arc:<人>:end",gte:1}` + 看法区间）。现在走完就断，池子于是净缩水。
4. **给 30 位客人补线**：优先补**已经在别人的卡里出现过的人**（宋姐、尹小洁、高原、裴岚、赵宁、段小姐），因为公平推理要求"凶手必须是读者已经认识的人"。目标第 1 季 12 → 20 人有线。
5. **有日期的死线**：每条线一个"错过就不演"的日子（Stardew 那句"条件不再可能满足的事件不会补演"），文案要在**门开着的时候**就说清"到第几天"（FL 那句"要让你挂多久你得知道"）。

## 5. 世界钟与沙漏：把"什么时候放卡"从抽取改成日程

四个计量，每个是一格一格的 quality，`endDay` / `beginSlot` 时按规则走，到刻度放主线卡（`{quality:"clock:<id>",gte:N}`）：

| 钟 | 走一格的条件 | 到刻度放什么 |
|---|---|---|
| 合规风向 `clock:wind` | 台账低 / 硬推成交 / 录音外流 | 巡店、备案、柜位那一栏自己往下掉 |
| 陆遥升势 `clock:rival` | 对面每请走一人 | 请人、抢客、第 3 幕那份合同 |
| 柜台租约 `clock:lease` | 每季固定 + 钱与柜位 | 第 4 幕那条线 |
| 闲话指数 `clock:gossip` | `backbite` / `quarrel` 的次数（现在狠推风格一季 131 次 `backbite`，完全没被用） | 谁进门时已经对你有看法、传话变味 |

**沙漏**：`thread:return-slip` 那四条线索同时填一个 `clue-count`，满 3 条时**允许**幕 2 的卡提前开门（现在只钉日期 ≥12）。这样"攒够了"这件事本身会推剧情，而不是等日历。

## 6. 说书人的张力义务

现在说书人只做合法性过滤 + 个人线权重 ×3。改成三条可核对的规则：

1. 每张卡打一个 **`situation`** 标签（12 个 Polti 式局面的本地版：欠债、救恩、复仇、误判、牺牲、野心、亲族相争、失踪、诱惑、背叛、认出、申冤）。
2. **每两个时段至少一张高张力的**：给卡一个 `tension` 1～3，说书人记住上一次放的是几，连续两张 ≤1 时第三次强制从 ≥2 的合法堆里抽。
3. **每个后果都要压上东西**：体力 / 合规 / 柜位 / 人情 / 一条能念的记忆。规则测试口径：`world-content` 现在要求"每个选项至少一个关系效果"，加一条"每张 `tension≥2` 的卡至少一个非关系效果"。

同时**不许把卡做成可刷的**：任何一张卡如果给净收益且无冷却，`world-lint` 要报（Wildermyth 的"farmable"就是循环失去意义的时刻）。

## 7. 收集与长尾：洞要看得见

- **本子页**（已落地）：`本子上攒了 N / 4 条` + 每条线一节，未攒到的压成？？？。
- **人物册**：每人 4～8 个"已记录状态"（秘密揭开、看法最好/最差、线的收法），档案里已经存 `bestOpinion` / `worstOpinion` / `secretKnown` / `arcEnds`，缺的是**把洞显示出来**（"还差 1 个"）。
- **结局表**：现在 13 个（含 3 个跨季）。目标 24 个，其中 8 个隐藏，隐藏的那几行在档案里念"？？？"+ 一句提示（`endingHint` 已有）。
- **传承（第 3 季后）**：一季结果 → 3～5 个代币（柜位、私域名单、一条未了结的秘密、一道疤），汇率写死并公示（Wildermyth 那套五档 1～5 点）。**先不做**，等四条线都齐了再说 —— 传承会改变"能读到哪些卡"，所以必须在卡够多之后加。

## 8. 内容预算与分期（每张卡按 300～500 字算）

现在的 166 字/张是主要缺口，所以**分期里第一批不是加卡，是加厚**：

| 轮 | 写什么 | 新增字数 | 验收口径 |
|---|---|---|---|
| R1 | 幕 2 的四条线补厚（`main-slip-yin` 的门放宽、第 5 档加代价）+ 每条现有卡补 1 个选项 | +8 k | 翻面率 ≥60% 且 yin 出场 ≥50/80；阀门占比从 26/80 降到 ≤16/80 |
| R2 | 闸门 + 引力井（清零、`visits:<id>`、12 张替代卡） | +12 k | 第 1 季个人线完成数落到 40～55/80；重复率从 50% 降到 ≤35% |
| R3 | 4 个世界钟 + 沙漏 + 说书人张力标签 | +14 k | 半池天数从 19 推到 ≥30；`tension≥2` 的卡每两时段至少一张（引擎测试） |
| R4 | 第 2、3 条线（差的那三天 / 谁在替谁带货）各 10 张 | +16 k | 两条线各自的四档都有分布，且幕号测试覆盖到第 3 幕 |
| R5 | 30 位客人补线（先 8 位）+ 人物册的洞 | +18 k | 有线人数 12 → 20；每张卡都出现过（模拟器已有的口径） |
| R6 | 幕 3、4 的收束与第 3 季 | +20 k | 三季跑完仍有 ≥25% 的卡没被读过 |

**总量**：R1～R6 约 88 k 字、约 150 张新卡 + 135 张加厚。**明确不承诺**"10～25 小时"这种市场口径 —— 那个需要 350～450 张（调研里算过），我们先用锁和计量把 135 张撑住，再按验收结果决定要不要继续加卡。

## 9. 验证契约（每轮都要跑，不许只改数字）

```bash
cd dynamic-counter-prototype
npm run test:rules                 # 含 world-clues / world-content / world-lint / world-recap / world-progress
node --experimental-strip-types tests/world-sim.ts 20 2     # 燃烧曲线 + 主线本子那一块
MOBILE_RUNTIME_TEST_PORT=4474 npx playwright test tests/world-season-smoke.spec.ts   # 浏览器真玩一季 + 第 2 季
npm run build
```

规则测试里必须钉住、且**新断言要先能红**的清单（反证做法：把要钉的性质故意改坏一次，看到红，再改回来）：

1. 幕号串行：`mainline:act = N` 时，第 N+1 幕的卡**不在**合法牌堆（`drawStorylet` 返回 null）。
2. 反转要证据：`thread:*` ≥1 且非阀门的那一档，其卡必须有 `{clue}` 门。
3. 阀门不早开：写 `thread:*` 而不以 `{clue}` 为门的卡，日期下限 ≥20。
4. 线索不死信：每条 `CLUES` 都被某张卡的 `when` 用到。
5. 公平性（R4 起）：收束卡引用的每个槽/旗，都能在更早的卡里找到来源。
6. 档案只增不减 + 类型不对整份丢弃（v1 形状的档案必须被拒）。
7. 燃烧曲线基线：半池天数、重复率、翻面率、阀门占比 —— 写成"不能往下/往上越过 X"的断言，而不是快照。

## 10. 明确不做

1. **不加第三层"通用动作卡"凑数** —— 灌水是最便宜的让游戏显得更短的方法。
2. **不用裸计时器锁人**（"再过 3 天"要配上"这三天里谁会来"这种看得见的东西）。
3. **不做进度条**：钟、本子、柜位、台账一律一句话说出来（沿用 `standingWord` / `complianceWord` 那条老规矩）。
4. **不为了通关率放宽证据门槛**：翻面率低就补链式入口，不是把 `turn` 的门改成 1 条线索。
5. **不在 UI 里拼本子的句子**：只读 `clues.ts`。
