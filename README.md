# 最后一单

现行可玩版本在 [`dynamic-counter-prototype/`](dynamic-counter-prototype/)。

这是商场美妆专柜生存游戏《最后一单》的五日原型。玩家扮演试用期柜姐许愿：观察面部线索、提问、试妆、应对截胡，并承担销售手段留下的后果。

```bash
cd dynamic-counter-prototype
npm install
npm run dev
```

默认打开 `http://127.0.0.1:5173/`。
