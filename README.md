# 最后一单 · 人情场

手机上的美妆专柜销售游戏。你是绮光专柜的新人 BA：

- **看 → 问 → 试 → 开单**：客人没说出口的，要靠看她的脸、挑一句问话、在手背上试一支摸出来，每一下都耗她一点耐心；件数开口太多她会不高兴。
- **一周一关**：周一罗曼报这周的业绩数，周日打烊对账盖星（到目标 / 赢对面 / 超额），季末把四关的星加起来，档案记最好的一季。
- **对面柜台**：维珞的陆遥抢的是同一批客人，每周比、季末总账也比。
- **人情网**：一层楼四十多个人各有脾气和熟人，你怎么待一个人会顺着网传出去；三百多张故事卡、二十条个人线、一条跨季的主线。

## 在哪

游戏本体在 [`dynamic-counter-prototype/`](dynamic-counter-prototype/)（代码在 `src/world/`）。根目录只转发命令：

```bash
npm --prefix dynamic-counter-prototype install
npm run dev          # http://127.0.0.1:5173/
npm run build
npm run test:rules
```

设计文档在 `docs/`：`人情场设计.md`（系统与改动历史）、`剧情主线设计.md`、`长线玩法提案.md`。
